# ネタバレなしハイライト

欧州サッカーのハイライトを「試合結果を見ずに」見るための、自分用のWebサイト。
DAZN Japan / U-NEXT フットボール / WOWOWサッカー の公式YouTubeチャンネルから、対象チームの試合のハイライトだけを集めて並べる。

公開先: https://taco-05.github.io/highlights/

## 大事なルール(ネタバレ防止)

- 画面には **試合結果・動画タイトル・サムネイル・動画の長さを出さない**。出すのは大会・節・チーム名・🇯🇵出場選手名だけ
- 🇯🇵は動画タイトルから「名前だけ」を拾う(「ゴール」「アシスト」などの中身は出さない)
- 動画は「再生」を押すまで読み込まない。再生が終わったら自動で閉じる(おすすめ動画のネタバレ防止)
- 再生中のYouTube側のタイトル表示は、YouTubeの規約上隠せないので対応しない(プレイヤーの上に物をかぶせない)

## ファイル

| 場所 | 中身 |
|---|---|
| `config/teams.json` | 対象チームと、各社の表記ゆれ(例: ゲンク=DAZNでは「ヘンク」)。プレミアは全チーム対象 |
| `config/japanese-players.json` | 欧州の日本人選手の名前リスト |
| `scripts/build.mjs` | 動画一覧から対象試合を選び、`site/data.js` を作る |
| `site/` | 公開されるサイト本体 |
| `review.json` | AIの点検用(未登録の名前候補・分解できなかったタイトル) |
| `serve.mjs` | 手元で確認するためのサーバー(`node serve.mjs` → http://localhost:4173) |

## 決まっていること

- 対象: ラ・リーガ5、プレミア全、ブンデス8(シャルケ含む)、リーグアン5、セリエA4、オランダ5、ポルトガル1、ベルギー6チーム + その試合のカップ戦・欧州カップ戦
- DAZNとU-NEXTの両方にある試合は、先に公開された方を使う
- 通知は 7時・11時・16時(前回以降の新着をまとめて。新着なしなら送らない)
